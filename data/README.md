# Data

Add the following files here before submitting to TICS:

| File | Description |
|------|-------------|
| `catalogue.csv` | Pitch–hue mapping systems (25 primary, 31 total retained) with CIELAB coordinates |
| `distance_matrix.csv` | Pairwise CIEDE2000 distances across all retained systems |
| `bootstrap_samples.npy` | 2,000 random-ensemble samples used for chance baseline (mean 0.212) |
| `family_assignments.csv` | System-to-family mapping with coder agreement log |

These files are referenced in the Open Practices Statement of the submission draft.
